# 🏋️ Фитнес-клуб «Сила» — API Infrastructure

Инфраструктура для демонстрации REST API доработки информационной системы фитнес-клуба «Сила».

## 📦 Что включено

- **PostgreSQL 15** — основная база данных с полной моделью данных
- **pgAdmin 4** — веб-интерфейс для работы с БД
- **Redis 7** — брокер сообщений для очереди уведомлений
- **Swagger UI** — визуализация OpenAPI спецификации

## 🚀 Быстрый старт

### 1. Запуск всех сервисов

```bash
docker-compose up -d
```

### 2. Проверка статуса

```bash
docker-compose ps
```

### 3. Доступ к сервисам

| Сервис         | URL                   | Логин            | Пароль                   |
| -------------- | --------------------- | ---------------- | ------------------------ |
| **Swagger UI** | http://localhost:8080 | —                | —                        |
| **pgAdmin**    | http://localhost:5050 | admin@silafit.ru | admin                    |
| **PostgreSQL** | localhost:5432        | silafit_admin    | silafit_secure_pass_2026 |
| **Redis**      | localhost:6379        | —                | —                        |

### 4. Остановка сервисов

```bash
docker-compose down
```

### 5. Полная очистка (удаление данных)

```bash
docker-compose down -v
```

## 🗄️ Модель данных

Полная модель данных включает:

### Существующие сущности (из Задания 6)

- `clients` — клиенты
- `memberships` — абонементы
- `classes` — групповые занятия
- `bookings` — бронирования
- `payments` — платежи

### Новые сущности (доработка)

- `access_cards` — электронные карты доступа (RFID)
- `visit_logs` — журнал посещений (вход/выход)
- `waitlist` — лист ожидания
- `trainers` — тренеры
- `personal_trainings` — персональные тренировки
